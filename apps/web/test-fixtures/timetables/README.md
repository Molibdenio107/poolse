# Timetable reader corpus — POOLSE-223

Six fictional timetables, each a folder with the document and `expected.json` (the rows of
meaning the reader must return). All are generated by `pnpm timetable:fixtures`
(`scripts/build-timetable-fixtures.mjs`); no club's real document is kept here.

| Case | What it tests |
|---|---|
| 01-monte-alvo-two-pools | two pools in one PDF, blocks across hours, two activities per cell by lane count, *Encerrado*, a legend, a footer and a tariff page |
| 02-one-pool-lane-names | 30-minute rows, lanes named ("Pistas 1-3") not counted, *Fechado* |
| 03-list-layout | one line per block (day, time, pool, activity, lane count) |
| 04-days-as-columns | each day a stack of time ranges, no time axis |
| 05-wall-photo | a tilted, slightly blurred JPEG of a wall sheet |
| 06-word-legend-above | legend and notes above the grid, a price in the notes |

`pnpm timetable:eval` reads each with the real model (it costs money: never in CI) and passes
when every expected row is found and no closed or legend row is read as an activity. A change to
`lib/timetable-reader-prompt.ts` ships with a recorded run.
