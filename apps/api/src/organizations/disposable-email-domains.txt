# Disposable e-mail domains refused at signup — POOLSE-62.
#
# Data, not code: nothing in the API names a domain, and this file is meant to be
# edited by whoever notices one. One domain per line, lowercase, no @.
# A line starting with # is a comment, so a domain can say why it is here.
#
# SIGNUP_DISPOSABLE_DOMAINS_FILE points somewhere else, which is how a domain is
# added or removed on a running deployment without shipping a build.
#
# It is a nuisance filter and never the protection: the block that matters is one
# trial per address, enforced by a unique index. Somebody determined will find a
# provider that is not on this list, and the ledger will still refuse them the
# second trial.
